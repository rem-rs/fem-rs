# Plan: fem-rs → MFEM parity in Elements/Spaces, AMR/NCMesh, Methodology

**Goal**: 100% MFEM feature parity in three focus areas:
- (A) Elements & FE Spaces
- (B) AMR / NCMesh
- (C) Methodology (DG, DPG, HDG, contact, plasticity, ROM, multiphysics, adjoint, XFEM, WG, VEM, shells, complex, DEC, topology-opt)

While preserving invariants:
- Rule D1: no external solver FFI; MultifrontalLu is the only direct backend
- Rule D2: docs are outdated; audit by source
- Rule D3: workspace excludes `fem-py` + `fem-benches` from `cargo build --workspace`
- Rule D4: don't mask real bugs with `_` prefix
- Rule D8: use `edit` tool for Unicode source files
- 2086 existing `#[test]` and 73 examples must stay green
- **Test policy (user chosen)**: MMS convergence + patch test for every new element/space; unit test for every new integrator
- **Scope (user chosen)**: implement all P1/P2/P3 including 5-star cost items (WG, VEM, DEC, shells, cut-cell, 3D XFEM)

**Size estimate**: ~6-12 months of focused work; 4 phases across ~120 sub-tasks. Each sub-phase is a stand-alone PR.

## Phase 0 — Silent-Behaviour Bug Hotfixes (days; ships first)

Audit found 5 silent behaviour bugs. Fix before feature work because later phases build on the same files.

### 0.1 Drucker-Prager plasticity dispatch — `crates/assembly/src/plasticity.rs`
- Bug: `PlasticConfig::drucker_prager(...)` builds α/k coefficients (L77, L102, L108) but the return-mapping loop always runs J2. Users silently get J2.
- Fix: `enum PlasticModel { J2, DruckerPrager, CamClay, Viscoplastic }`; branch stress update; DP → cone/apex projection (Simo & Hughes §7.5).
- Test: uniaxial compression with c=0, φ=30° → yield surface matches analytical DP.

### 0.2 Roe flux stub — `dg_euler_2d.rs:52-54`, `dg_euler_3d.rs:21`
- Bug: `RiemannSolver::Roe` dispatches to `lax_friedrichs_flux`.
- Fix: proper Roe averaging (LeVeque §15.3): {ρ̂, û, ĥ}, wave strengths, Harten-Hyman entropy fix. Keep LxF as fallback.
- Test: 1-D Sod tube; Roe contact discontinuity smeared ≤ 2Δx.

### 0.3 DG elasticity scalar-block-diagonal — `dg_elasticity.rs:12-16, 20-43`
- Bug: two decoupled Poissons, no λ/μ coupling.
- Fix: full C:∇u tensor in interior integrator + SIP/BR2 face flux for vector case; 2D + 3D.
- Test: patch test (u=x+y in 2D, u=x+y+z in 3D) → exact recovery; MMS for λ=1, μ=0.5.

### 0.4 Adjoint order-inconsistency — `crates/solver/src/adjoint.rs:74-140`
- Bug: forward RK4, backward BE → adjoint gradient is O(dt), not O(dt⁴). Confirms Rule-D4 `t` accumulator smell.
- Fix: discrete-adjoint-over-RK (Sanders formulas) + Griewank multi-level binomial checkpointing.
- Test: analytical dJ/dθ for J=∫u² with u̇=-θu → error ≤ O(dt⁴).

**Phase 0 deliverable**: PR-0 (5 hotfixes); tests grow 2086 → ~2100.

### Risk register

- **R1 Bergot-Cohen-Durufle pyramid basis (1B.3, 1B.4)**: collapsed-coord math is subtle; apex singularity. Mitigation: reference impl from Bergot 2010 paper + validation vs MFEM `PyramidTypeFiniteElement`.
- **R2 High-order NC on vector-FE (2B.1)**: moment-matrix construction for ND2/RT2 face DOFs needs care (Belgacem-Maday). Existing `compute_rtk_subface_transform` partially done, ND2 tangential still linear-approx. Mitigation: correctness test with polynomial exactness across hanging face.
- **R3 VEM stabilization tuning (1C.2)**: `alpha_E` (dofi-dofi) is problem-dependent. Mitigation: use Beirao-Brezzi-Marini standard for Poisson/elasticity, empirical for Stokes.
- **R4 Cut-cell quadrature ill-conditioning (1C.3)**: small cut cells give arbitrarily bad cond number. Mitigation: mandatory ghost-penalty stabilizer + cell agglomeration option (Kummer 2017).
- **R5 3D XFEM sub-cell integration (3J)**: 3D level-set sub-tet is more complex than 2D. Mitigation: use Saye's algorithm from 1C.3 as substrate.
- **R6 Krivodonova/WENO limiter (3A.2) on 3D unstructured DG**: stencil reconstruction is open research. Mitigation: ship 2D first, mark 3D follow-up.
- **R7 Discrete adjoint over arbitrary Butcher (3H.3)**: symplectic-adjoint pairing subtlety. Mitigation: explicit RK first, then implicit.
- **R8 3D Mortar surface clipping (3D.4)**: robustness of face-face intersection. Mitigation: Puso-Laursen segment-to-segment; Shewchuk robust predicates.
- **R9 Compile-time explosion**: 78KLOC of generics may cripple incremental build. Mitigation: dyn-trait boundary at FE-space level; monomorphized fast paths only in hot integrators; regular `cargo bloat` audits.
- **R10 Test-time explosion**: ~1585 new tests may inflate CI 10 -> 40+ min. Mitigation: `#[ignore]` heavy tests behind `--include-ignored`; nightly-only for perf MMS.

### Verification of "100% parity"

Definition of done per area:

- **Area A (Element/Space)**: coverage matrix all cells filled with 1+ passing test; MMS convergence orders match theoretical; unit tests exercise every ReferenceElement impl for shape/grad/hessian/quadrature/dof_coords.
- **Area B (AMR/NCMesh)**: all 6 shapes have {uniform, NC, aniso, multi-level rollback, all constraint kinds, prolongation, derefine, p-refine, estimators, hp-marking} passing. L-shape 2D+3D achieves theoretical convergence rate.
- **Area C (Methodology)**: each MFEM ex-suite counterpart runs to within 1% of published result or converges at expected order. Every silent-behavior bug closed with regression test.

Additionally, produce `docs/mfem_parity_report.md` at end enumerating: (a) every MFEM feature by name, (b) fem-rs counterpart file:line, (c) test verifying parity, (d) known deviations with rationale.
