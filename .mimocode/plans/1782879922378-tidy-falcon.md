## 二、fem-rs 与 MFEM 对齐的部分 (已达标)

### 2.1 有限元空间 (基本对齐)
- H1 连续 Lagrange (P1-P10)
- L2 间断 Lagrange (P0-P3)
- H(curl) Nedelec (ND1/ND2/NDk) on Tri/Quad/Tet/Hex
- H(div) Raviart-Thomas (RT0/RT1/RT2/RTk) on Tri/Tet; RT0/RT1/RTk on Quad/Hex
- BDM on Tri/Quad/Tet
- VectorH1 (弹性力学/Stokes)
- BlockFE 空间 (混合问题)
- IGA/B-spline/NURBS 空间
- 1-form de Rham 复合 (Gradient/Curl/Divergence 离散算子)

### 2.2 网格能力 (基本对齐)
- SimplexMesh 支持所有 6 种几何体 (Tri/Quad/Tet/Hex/Prism/Pyramid)
- 网格生成: unit_square_tri/quad, unit_cube_tet/hex, periodic
- 网格变换: translate/scale/rotate/transform
- CurvedMesh (等参高阶几何)
- TMOP 网格优化 (14 种质量度量)
- 子网格提取 (SubMesh)
- 混合网格 (mixed element support)
- 网格 I/O: MFEM .mesh v1.0/v1.2 读取兼容

### 2.3 装配框架 (基本对齐)
- BilinearForm / LinearForm / MixedForm
- 标准积分器: Diffusion/Mass/Elasticity/Convection/CurlCurl/GradDiv/VectorMass/VectorDiffusion
- DG: SIP interior penalty + upwind advection
- HDG: Poisson/Elasticity/Maxwell/Stokes
- DPG: 1D/2D/3D
- Mortar 方法
- Nonlinear form + Newton/JFNK/Anderson 加速
- Static condensation
- Block assembly (2x2 saddle-point)
- 复数装配 (频域 Maxwell)
- 系数系统 (Coefficient trait)
- Partial assembly / matrix-free 算子

### 2.4 求解器 (基本对齐)
- Krylov: CG, GMRES(restart), FGMRES, BiCGSTAB, IDR(s), TFQMR, MINRES
- ILU 家族: ILU(0), ILU(k), ILUT, ILDLT
- AMG: SA-AMG, RS-AMG, AIR, Chebyshev 平滑, V/W/F 循环
- AMS (Hiptmair-Xu for H(curl))
- ADS (Hiptmair-Xu for H(div))
- 直接: LU, Cholesky, LDLT (via linlvo)
- 几何多重网格 (LOR-based)
- p-多重网格 + FMG
- 块预条件器: BlockDiagonal, BlockTriangular, Schur complement
- 特征值: LOBPCG, Krylov-Schur
- 混合精度: f64→f32 preconditioner

### 2.5 时间积分 (与 MFEM 对齐甚至超越)
- 显式: ForwardEuler, Heun, RK4, Dormand-Prince(4/5), Fehlberg, Bogacki-Shampine, Cash-Karp
- 隐式: ImplicitEuler, SDIRK(2/3/4), BDF(变阶), ImplicitMidpoint
- IMEX: ImexEuler, ImexSsp2, ImexArk3, ImexRk3
- 结构: Newmark, GeneralizedAlpha
- 辛: Verlet, Leapfrog, Yoshida4
- 自适应步长 (PI/WRMS 控制器)
- 多速率时间步进
- SDC (谱延迟校正)
- 伴随灵敏度分析
- DAE 求解器

### 2.6 并行计算 (基本对齐)
- MPI 后端 (rsmpi) + Thread 后端 + WASM Worker 后端
- ParCsrMatrix + ParFESpace + GhostExchange
- ParAssembler / ParVectorAssembler
- 网格分区: 纯 Rust BFS k-way + RCB + SFC + METIS 集成
- 并行 AMG (ParAmgHierarchy)
- RAS 预条件器
- 并行 HDF5 checkpoint I/O
- 强/弱可扩展性有实测数据

### 2.7 自适应网格细化 (基本对齐)
- Newest-vertex bisection (Tri)
- Red refinement (Tri→4 children)
- Non-conforming refinement (Tri/Tet/Quad/Hex, 含各向异性)
- Uniform refinement (2D/3D)
- 误差估计器: ZZ (Zienkiewicz-Zhu), Kelly, DWR
- Dorfler (bulk) marking
- p-refinement: 变阶 DOF 管理 + order smoothing
- Hanging node constraints
- Transfer operators: prolongation/restriction for H1/HCurl/HDiv
- CurvedMesh refinement

## 三、fem-rs 超越 MFEM 的部分

### 3.1 WASM 支持
- **fem-wasm**: 浏览器端 Poisson 求解器, WebWorker 多线程
- MFEM 无官方 WASM 支持

### 3.2 Python 绑定 (更现代)
- **PyO3 + maturin** 构建, abi3 兼容
- UFL-like 表单编译器 (`forms.py`)
- SciPy 互操作
- MFEM 的 Python 绑定基于 gltcl/Tcl, 较老旧

### 3.3 纯 Rust 实现
- 零外部 C/Fortran 依赖 (除 MPI/HDF5 可选)
- 内存安全, 无 UB
- MFEM 依赖 HYPRE/METIS/ParMETIS 等 C/C++ 库

### 3.4 纯 Rust 图分区
- **fem-rmetis**: multilevel k-way, 纯 Rust 实现
- MFEM 依赖 METIS/ParMETIS

### 3.5 IMEX 方法更丰富
- ImexEuler, ImexSsp2, ImexArk3, ImexRk3
- MFEM 主要提供 ARKODE 集成

### 3.6 多物理场模板
- multiphysics_templates.rs 提供预定义耦合模板
- FSI (流固耦合)、热弹性、相场断裂等专用模块

### 3.7 混合精度
- f64→f32 preconditioner, f32 GPU 求解
- MFEM 无内置混合精度支持

### 3.8 SDC (谱延迟校正)
- SdcIntegrator + SdcConfig
- MFEM 无内置 SDC

### 3.9 晶体塑性
- crystal_plasticity.rs
- MFEM 无内置晶体塑性

## XFEM 实现计划

### 1. 概述

实现扩展有限元法（XFEM）用于线弹性断裂力学：Heaviside 富集（强间断） + 裂尖分支富集（渐近场）。

XFEM 与标准 FEM 的核心区别：

| 方面 | 标准 FEM | XFEM |
|------|----------|------|
| 网格 | 网格必须拟合裂纹 | 网格独立于裂纹，裂纹由水平集描述 |
| 形函数 | 标准 Lagrange | 标准 + 富集形函数 (H(x)·N(x) + F_i(r,θ)·N(x)) |
| DOFs | 每个节点 1 个 DOF | 富集节点有额外 DOFs |
| 积分 | 单元内 Gauss 积分 | 被切割单元需子网格积分 |
| 裂纹面 | 需接触约束 | Heaviside 富集自然产生间断 |

### 2. 体系结构

#### 2.1 新增文件

| 文件 | 职责 |
|------|------|
| `crates/assembly/src/xfem.rs` | XFEM 主模块：富集管理、子网格积分、装配 |
| `crates/assembly/src/xfem_level_set.rs` | 水平集类型（从 ex38 抽取）：Circle、Halfspace、LineSegment |
| `crates/assembly/src/xfem_integrators.rs` | XFEM 积分器：弹性矩阵、质量矩阵、源项（含富集项） |

总代码量估计：~800-1200 行

#### 2.2 水平集 (`XfemLevelSet`)

从 ex38 示例提取 `LevelSetShape`，扩展为完整的水平集工具：

```rust
pub enum XfemLevelSet {
    Circle { cx: f64, cy: f64, radius: f64 },
    Halfspace { normal: [f64; 2], offset: f64 },
    LineSegment { x1: [f64; 2], x2: [f64; 2] },  // 裂纹线
}

impl XfemLevelSet {
    pub fn eval(&self, x: [f64; 2]) -> f64;         // ψ(x)
    pub fn normal(&self, x: [f64; 2]) -> [f64; 2];  // 单位外法向
    pub fn is_positive(&self, x: [f64; 2]) -> bool;  // ψ(x) > 0？
}
```

#### 2.3 富集管理 (`XfemEnrichment`)

```rust
pub enum EnrichmentType {
    Heaviside,          // H(x) 阶跃富集
    TipBranch,          // 裂尖分支富集 (4个函数)
}

pub struct XfemEnrichment {
    // 每个节点的富集类型列表
    pub enriched_nodes: Vec<(usize, EnrichmentType)>,
    // 每个富集 DOF 的全局索引
    pub enriched_dofs: Vec<DofId>,
}
```

- **Heaviside 富集**: 裂纹穿过的单元节点被富集。额外 DOF 乘 H(x)，其中 H(x) = ±1 取决于点在裂纹哪一侧。
- **Tip 分支富集**: 含裂尖的单元节点被富集。4 个分支函数：
  - F₁(r,θ) = √r · sin(θ/2)  — 位移间断
  - F₂(r,θ) = √r · cos(θ/2)
  - F₃(r,θ) = √r · sin(θ/2)·sin(θ)
  - F₄(r,θ) = √r · cos(θ/2)·sin(θ)

#### 2.4 子网格积分 (`XfemSubGridIntegration`)

被裂纹切割的单元需要分裂为子三角形，在每个子三角形上做标准 Gauss 积分：

```rust
pub struct XfemSubGrid {
    pub subtriangles: Vec<[[f64; 2]; 3]>,  // 子三角形的顶点(参考坐标)
}
```

算法：对每个单元，根据水平集 ψ 在 3 个顶点的符号 (±) 确定切割模式：
- 全正/全负：标准积分（无切割）
- 混合符号：用 `triangle_level_set_chord` 找到边缘交点，分裂为 2 或 3 个子三角形

#### 2.5 XFEM 装配 (`XfemAssembler`)

```rust
pub struct XfemAssembler;

impl XfemAssembler {
    pub fn assemble_stiffness(
        space: &H1Space<SimplexMesh<2>>,
        enrichment: &XfemEnrichment,
        ls: &XfemLevelSet,
        lame_lambda: f64,
        lame_mu: f64,
    ) -> CsrMatrix<f64>;
}
```

装配流程：
1. 遍历所有单元
2. 检查单元是否有富集节点
3. 若无：标准弹性矩阵装配（用现有 `ElasticityIntegrator`）
4. 若有：子网格分裂 → 对每个子三角形做 Gauss 积分
   - 在子三角形每个 QP 处计算标准形函数 Nᵢ 和富集形函数 Nᵢ·H(x) 或 Nᵢ·Fₖ(r,θ)
   - 计算 B 矩阵（应变-位移）
   - 累加至元素刚度矩阵
5. 应用 Dirichlet BCs（在标准 + 富集 DOFs 上）

### 4. 关键数学公式

**XFEM 近似**:
```
u^h(x) = Σ Nᵢ(x)·uᵢ + Σ Nⱼ(x)·H(x)·aⱼ + Σ Nₖ(x)·(Σ Fₗ(r,θ)·cₖₗ)
        标准 DOFs          Heaviside 富集 DOFs       裂尖富集 DOFs
```

**B 矩阵扩展**:
标准弹性：B_std = [∂N/∂x, 0; 0, ∂N/∂y; ∂N/∂y, ∂N/∂x]
Heaviside：B_enr = H(x) · B_std + N(x) · (∂H/∂x) 其中 ∂H/∂x = 0 处处（除裂纹面外）
Tip：B_tip 包含分支函数的梯度

**单元刚度**:
```
k_e = ∫_Ωₑ (B_std + B_enr)ᵀ · D · (B_std + B_enr) dΩ
```

被切割单元用子三角形 Gauss 积分：
```
k_e = Σ_subtri Σ_qp B(x_qp)ᵀ · D · B(x_qp) · w_qp · |J|
```

### 7. 风险

| 风险 | 缓解 |
|------|------|
| 子网格积分实现复杂 | 从 ex38 的 chord 算法做增量扩展 |
| 富集 DOF 与现有 FESpace 框架集成复杂 | 用扁平 DOF 管理（标准 + 富集向量拼接），不修改现有空间 |
| 裂尖分支函数在极坐标下导数有奇异性 | 在 r→0 时做特殊处理，裂尖位移不直接求解 |
| Blending 单元精度损失 | 仅全富集/非富集，过渡单元做简单加权 |

## 八、总结

fem-rs 在**功能覆盖度**上已达到 MFEM 的 ~85%, 在**测试质量**、**Python 绑定**、**WASM 支持**、**纯 Rust 实现**等方面甚至超越 MFEM。主要差距集中在:

1. **GPU 加速** — 最大短板, 需要 6-8 周集中攻关
2. **NCMesh 成熟度** — 需要 4-6 周完善
3. **方法/积分器覆盖** — LDG/XFEM/Surface PDE 等
4. **性能优化** — assembly 和并行扩展性
5. **文档/教程** — 用户友好性

按上述 6 个 Phase 推进, 预计 24-34 周可达到 MFEM 功能对齐。
