# Plan: GPU PA 性能基准验证

## 目标
运行 GPU Partial Assembly 性能基准，验证 CPU vs GPU 加速比 ≥ 5x。

## 当前状态
- `crates/benches/pa_gpu.rs` — 存在但**仅有 CPU PA benchmarks**（`pa_cpu_apply` / `pa_cpu_build`）
- GPU PA apply 函数已实现于 `crates/linalg-gpu/src/pa_apply.rs`（`gpu_pa_apply_hex_q1..q4`, `gpu_pa_apply_tet4`）
- 但 **未接入 criterion benchmark**

## 步骤

### 1. 添加 GPU PA benchmark 到 `pa_gpu.rs`
在现有 CPU benchmark 旁边加 GPU 对应的 benchmark group `pa_gpu_apply`：
- 构建 GpuContext
- 调用 `gpu_pa_apply_hex_q1` 等
- 与 CPU 版本同规模（10³/20³/40³/80³）

### 2. 运行基准
```bash
FEM_BENCH_QUICK=1 cargo bench -p fem-benches --bench pa_gpu
```

### 3. 分析结果
- 对比 `pa_cpu_apply/hex_q1/{dof}` vs `pa_gpu_apply/hex_q1/{dof}`
- 目标：≥ 5x 加速（≥ 1M DOF）
- 若 80³ (531K DOF) 不够，加 100³ 规模

## 关键文件
- `crates/benches/pa_gpu.rs` — 修改
- `crates/linalg-gpu/src/pa_apply.rs` — GPU PA apply 函数
- `crates/linalg-gpu/src/context.rs` — GpuContext 初始化
- `crates/linalg-gpu/src/backend_wgpu.rs` — WgpuBackend

## 验收
- `cargo bench -p fem-benches --bench pa_gpu` 输出含 GPU 组
- 在 `docs/baselines/` 记录加速比数据
