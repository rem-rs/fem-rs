# P2-1: GPU 装配加宽

## 目标
扩展 GPU 装配的覆盖面和精度，对齐验收标准：
- f64 GPU COO 装配（`GpuCooTriplet<f64>`），CPU/GPU 元素级相对误差 < 1e-12
- 新增 WGSL shader：Poisson Tet4 / Hex8、Mass Tet4 / Hex8、Elasticity Tet4 / Hex8

## 现状分析

### 已有 WGSL shader
| Shader | 单元 | PDE | 精度 |
|--------|------|-----|------|
| assembly_poisson_tri3 | Tri3 | Poisson | f32 |
| assembly_mass_tri3 | Tri3 | Mass | f32 |
| assembly_elasticity_tri3 | Tri3 | 弹性 | f32 |
| assembly_poisson_tri6 | Tri6 | Poisson | f32 |
| assembly_poisson_tet4 | Tet4 | Poisson | f32 |
| assembly_mass_tet4 | Tet4 | Mass | f32 |
| assembly_poisson_quad4 | Quad4 | Poisson | f32 |
| assembly_mass_quad4 | Quad4 | Mass | f32 |
| assembly_poisson_hex8 | Hex8 | Poisson | f32 |
| assembly_mass_hex8 | Hex8 | Mass | f32 |

### 已有 Rust 入口
`crates/linalg-gpu/src/assembly.rs`:
- `assemble_poisson_gpu` — 可选 tet4/hex8/tri3（`GpuCsrMatrix<f64>` 返回，但内部 COO 是 f32）
- `assemble_mass_2d_tri3_gpu` — f32 COO → f64 CSR
- `assemble_elasticity_2d_tri3_gpu` — f32 COO → f64 CSR

### GpuCsrMatrix 已支持 f64
- `crates/linalg-gpu/src/csr.rs` 的 `GpuCsrMatrix<T>` 是泛型的（f32/f64）
- GPU CG/PCG 已有 f64 路径
- SpMV 有 f64 WGSL shader

### 关键差距
1. **GpuCooTriplet.val 是 f32**（`assembly.rs:71`）— 所有装配都用 f32
2. **弹性 Tet4/Hex8** — 完全无 WGSL shader
3. **无高阶 shader** — Tri P2 等

## 实现计划

### Step 1: GpuCooTriplet<f64> 支持
**文件**: `crates/linalg-gpu/src/assembly.rs`
- 将 `GpuCooTriplet` 改为泛型 `GpuCooTriplet<T>`（f32 或 f64）
- 添加 `GpuCooTripletF32` 别名（保持向后兼容）
- 修改 `run_assembly_shader` 接收泛型输出缓冲
- 在 `assemble_poisson_gpu` 中增加 f64 路径分支

### Step 2: Tet4/Hex8 弹性 WGSL shader
**新文件**: `crates/linalg-gpu/src/assembly_elasticity_tet4.wgsl`
- 4 节点 × 3 坐标 = f32[12] 坐标
- 4 节点 × 3 DOF = f32[12] DOF 索引
- 常量应变 tetrahedron（B^T C B formulation）
- 每个元素 48 COO triplets（4×4 节点 × 3×3 分量）

**新文件**: `crates/linalg-gpu/src/assembly_elasticity_hex8.wgsl`
- 8 节点 × 3 坐标 = f32[24] 坐标
- 8 节点 × 3 DOF = f32[24] DOF 索引
- 8 积分点高斯求积（2×2×2）
- 每个元素 576 COO triplets 或类似

### Step 3: f64 GPU 装配入口
**文件**: `crates/linalg-gpu/src/assembly.rs`
- `assemble_poisson_gpu_f64` — f64 COO 路径
- `assemble_mass_gpu_f64` — f64 COO 路径
- `assemble_elasticity_gpu_f64` — f64 COO 路径
- 统一 CPU→GPU 上传 + GPU COO → GPU CSR 管线

### Step 4: 测试
**文件**: `crates/linalg-gpu/tests/` 或 `crates/assembly/tests/`
- 新增每个 shader 的 CPU-vs-GPU 等价性测试
- `assembly_poisson_tet4_f64_gpu_matches_cpu`
- `assembly_elasticity_hex8_gpu_matches_cpu`
