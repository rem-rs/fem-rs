# P4.1 — 分布式直接求解器增强（Schur 补 + RAS+MultifrontalLu）

## 背景

P4.1 要求自研分布式多波前直接解，基于 `linger::MultifrontalLu`。MEMORY.md 明确允许降级到 "selected inversion + 局部 Schur + 全局 GMRES" 作为高鲁棒 fallback。

当前进展：
- `RasPrecond` 已支持 `RasLocalSolverKind::MultifrontalLu`（本次会话新增）
- `par_solve_gmres_ras` / `par_solve_pcg_ras` 提供全局 Krylov + RAS 预条件
- `ParCsrMatrix`、`ParVector`、`GhostExchange` 基础结构完备

## 目标

在现有 RAS 基础上增强，实现真正的**分布式直接求解**能力：

1. **Schur 补预条件** — 将每个子域的内点 DOF 用 MultifrontalLu 消去，只剩界面 DOF 的全局 Schur 补系统
2. **多遍 RAS** — 在 overlap>0 时允许多次局部-全局迭代
3. **BLR 压缩** — 对超大子域启用 BLR 近似，作为预条件加速

## 实现计划

### Step 1: SchurComplementPrecond（新结构）

在 `crates/parallel/src/par_ras.rs` 中新增：

```rust
/// Schur 补预条件器：A = [A_II, A_IB; A_BI, A_BB]
/// M^{-1} = [A_II^{-1}, 0; 0, S^{-1}] 其中 S = A_BB - A_BI * A_II^{-1} * A_IB
pub struct SchurPrecond {
    /// Local interior solver: MultifrontalLu for A_II
    local_solver: linlvo::direct::MultifrontalLu<f64>,
    /// Interface stiffness: A_BB (assembled across ranks as ParCsrMatrix)
    interface_a: Option<ParCsrMatrix>,
    /// A_BI * A_II^{-1} * A_IB (local Schur complement)  
    local_schur: Option<CsrMatrix<f64>>,
    /// Precomputed S^{-1} as a local dense approximation (diagonal or LU)
    schur_inv: Option<Vec<f64>>,
}
```

实现：
- `SchurPrecond::build(a, local_dof_map)` — 从 ParCsrMatrix 提取 I/B 分块，对 A_II 做 MultifrontalLu factor
- `SchurPrecond::apply(r, z)` — 先局部求解内点，再处理界面耦合

### Step 2: `par_solve_gmres_schur`（新函数）

全局 GMRES 仅作用在界面 DOF 的 Schur 补系统上：

```rust
pub fn par_solve_gmres_schur(
    a: &ParCsrMatrix,
    schur: &SchurPrecond,
    b: &ParVector,
    x: &mut ParVector,
    restart: usize,
    cfg: &SolverConfig,
) -> Result<SolveResult, SolverError>
```

### Step 3: 多遍 RAS

增强 `RasPrecond` 支持 `n_sweeps > 1`：每一遍交替做 local solve + ghost exchange，类似 multiplicative Schwarz。

### Step 4: BLR MultifrontalLu 作为预条件

在 `RasConfig` 中添加 `use_blr: Option<(f64, usize)>`，当设置时使用 `MultifrontalLu::with_blr(tol, min_size)` 而非 exact 因子分解。

## 涉及文件

| 文件 | 改动 |
|---|---|
| `crates/parallel/src/par_ras.rs` | 新增 SchurPrecond、par_solve_gmres_schur、多遍 RAS 支持、BLR 选项 |
| `vendor/linger/src/direct/multifrontal.rs` | （无需改动，已有 BLR 支持） |
| `crates/parallel/src/lib.rs` | 导出新类型和函数 |

## 测试验证

1. **单 rank 测试**：SchurPrecond 在 size=1 时退化为 MultifrontalLu，`par_solve_gmres_schur` 应与直接求解一致
2. **双 rank 测试**：用 4×4 网格分区验证 Schur 补预条件 GMRES 收敛
3. **BLR 测试**：验证 `use_blr` 选项构建成功且返回有限值
4. **多遍 RAS**：验证 `n_sweeps=row` 与 `n_sweeps=1` 迭代次数减半
