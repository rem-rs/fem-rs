# Phase 3.2: Hyperelasticity — Neo-Hookean + Newton

## Goal
Implement compressible Neo-Hookean hyperelasticity with the Newton–Raphson solver:
```
∫_Ω P(F) : ∇v dV = 0  (residual)
∫_Ω C : (∇δu) : ∇v dV  (tangent stiffness)
```

## Design

### Struct
```rust
pub struct HyperelasticityForm<M: MeshTopology> {
    space: VectorH1Space<M>,
    lambda: f64,      // First Lamé parameter
    mu: f64,          // Second Lamé parameter (shear modulus)
    dirichlet: Vec<(usize, f64)>,
    quad_order: u8,
}
```

### Neo-Hookean model (compressible)
Strain energy: `ψ = μ/2 (tr(C) - dim) - μ·ln(J) + λ/2·(ln(J))²`
- `F = I + ∇u` — deformation gradient
- `C = FᵀF` — right Cauchy-Green
- `J = det(F)` — volume change
- `P = μ·F + (λ·ln(J) - μ)·F⁻ᵀ` — 1st Piola-Kirchhoff stress

### Tangent modulus (consistent)
```
∂P_{iI} / ∂F_{jJ} = μ·δᵢⱼ·δᴵᴶ + λ·(F⁻¹)ᴵₖ·(F⁻¹)ᴶₖ·δᵢⱼ
                   - (λ·ln(J) - μ)·(F⁻¹)ᴶᵢ·(F⁻¹)ᴵⱼ
```
This gives the material tangent stiffness (non-symmetric in I,J for the geometric part).

### Key formulas per quadrature point

Given `u_elem[node * dim + d]` and `grad_phys[node * dim + d]`:
```
// Displacement gradient
for i in 0..dim:
  for j in 0..dim:
    du[i][j] = Σ_node u_elem[node*dim + i] * grad_phys[node*dim + j]

// Deformation gradient
F[i][j] = (i==j) + du[i][j]
J = det(F)
F_invT = (F⁻¹)ᵀ

// PK1 stress
P[i][j] = mu * F[i][j] + (lam * ln(J) - mu) * F_invT[i][j]
         // (for 2D plane strain: F[2][2]=1, dim effective = 2 + 1 for trace)

tangent[i][j][a][b] = mu * δᵢₐ * δⱼ_b
    + lam * Σ_k F_invT[j][k] * F_invT[b][k] * δᵢₐ
    - (lam * ln(J) - mu) * F_invT[a][j] * F_invT[b][i]
```

### Element matrix assembly (jacobian)
```
k_elem[row][col] += w · Σᵢⱼ Σₐᵦ tangent[i][j][a][b] 
                   * grad_test[row/dim][j] * grad_trial[col/dim][b]
                   * δ(row%dim, i) * δ(col%dim, a)
```
where row = node_k * dim + component_i, col = node_l * dim + component_a.

### Element residual assembly
```
f_elem[row] += w · Σᵢⱼ P[i][j] * grad_phys[node_k][j] * δ(row%dim, i)
```

### Dirichlet BC
Same pattern as NonlinearDiffusionForm: zero row `d` in Jacobian, set diagonal to 1, residual `r[d] = u[d] - val`.
