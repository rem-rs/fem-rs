# VEM 完整空间模块实现计划

## 目标
创建完整的 VEM 空间模块（对应 MFEM 的 `VEMSpace`），使现有 `vem_poisson.rs` 装配器使用标准 FESpace 接口，支持 2D 多边形网格上的 P1 VEM。

## 设计

### 1. `ElementType::Polygon` 变体
**文件**: `crates/mesh/src/element_type.rs`
- 添加 `Polygon` 到 `ElementType` 枚举
- `nodes_per_element` = 0 表示可变顶点数
- `is_simplex` = false
- `is_tensor_product` = false

### 2. `PolyMesh<const D: usize>` — 多边形网格
**文件**: `crates/mesh/src/poly_mesh.rs`
- 实现 `MeshTopology` trait
- 数据结构:
  - `coords: Vec<f64>` — 平铺节点坐标，长度 `n_nodes * D`
  - `conn: Vec<u32>` — 平铺单元连通性
  - `offsets: Vec<usize>` — 每个单元的连通性偏移量（CSR 风格）
  - `D` — 维度（仅支持 2）
- `element_node(elem)` → `&conn[offsets[elem]..offsets[elem+1]]`
- `element_type(_)` → `ElementType::Polygon`
- 生成函数: `unit_square_quad(n)` — n×n 四边形网格，`unit_square_hex(n)` — n×n 六边形网格

### 3. `VEMSpace<M>` — VEM 有限元空间
**文件**: `crates/space/src/vem.rs`
- 泛型结构体 `VEMSpace<M: MeshTopology>`
- 实现 `FESpace` trait
- 字段:
  - `mesh: M`
  - `order: u8` (= 1 for P1 VEM)
  - `n_dofs: usize` = `mesh.n_nodes()`
- `element_dofs(e)` = 与 `element_nodes(e)` 相同的全局 DOF（P1 VEM：每个顶点一个 DOF）
- `interpolate(f)` → 在每个节点坐标处评估 f 的向量
- 新增方法 `element_vertices(elem) -> &[NodeId]` 用于装配器访问

### 4. 添加 `SpaceType::VEM`
**文件**: `crates/space/src/fe_space.rs`
- 添加 `VEM` 变体到 `SpaceType` 枚举

### 5. 重构 `assemble_vem_poisson`
**文件**: `crates/assembly/src/vem_poisson.rs`
- 新签名: `pub fn assemble_vem_poisson(space: &VEMSpace<PolyMesh<2>>) -> CsrMatrix<f64>`
- 保留内部几何计算（`poly_area`, `centroid`, `poly_int`, P1 投影）
- 通过 `space.mesh()` 访问坐标/连通性
- 通过 `space.element_dofs(e)` 获取 DOF

### 6. 注册模块
**文件**:
- `crates/mesh/src/lib.rs` — 添加 `pub mod poly_mesh;`
- `crates/space/src/lib.rs` — 添加 `pub mod vem;`

### 7. 测试
- 更新现有 4 个 VEM 测试使用 `VEMSpace` + `PolyMesh`
- 添加 `vem_space_*` 测试验证空间结构
