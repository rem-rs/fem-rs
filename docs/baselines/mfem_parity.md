# MFEM 对照基线

## 目标

为 Poisson / Elasticity / Maxwell / Stokes 建立 setup / assemble / solve 三段性能基线，
scale 从 10K DOF 到 1M DOF，作为后续优化的对照。

## 运行方式

```bash
cargo bench -p fem-benches --bench mfem_parity
```
